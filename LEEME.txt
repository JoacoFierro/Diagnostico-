Versiones:

PHP Version: OS Default Version (8.4.14)
PostgreSQL 18.0

Observaciones:

- Se construyo el proyecto en Windows 11.
- Se utilizo PHP VS17 x64 Non Thread Safe ZIP y se agrego al Path de Variables del sistema.
- Se debe habilitar las extensiones: pdo_pgsql y pgsql en el php.ini y descomentar la linea de codigo: extension_dir = "ext"
- Se recomienda usar Visual Studio Code.

Instrucciones para descargar el proyecto:
1. Cree un directorio y entre en el.
2. Abra la terminal y ejecute el siguiente comando: git clone https://github.com/JoacoFierro/Diagnostico-.git
3. Ingrese al directorio creado recientemente.

Instrucciones para iniciar base de datos:
1  Instale pgAdmin 4
2. Ejecute pgAdmin 4
3. Agregue un nuevo Server llamado Tarea
4. Añada un base de datos con los siguentes parámetros: 

    Host name = localhost
    Port = 5432
    Maintance Database = postgres
    Username = postgres
    Password = 1234

5. Asi tendra la base de datos activa


Instrucciones para ejecutar formulario:
1. Debe tener la base de datos activa
2. Ejecute el archivo "CreacionPoblaciomiento.php" dentro del directorio de "Servidor" con el comando: php CreacionPoblamiento.php
3. Vuelva a estar en el directorio donde esta el archivo formulario.html
4. Ejecute el siguiente comando en la terminal para iniciar el servidor: php -S localhost:8000
5. Abra el navegador y pegue la siguiente direccion en la barra de busqueda: http://localhost:8000/formulario.html
